Dokumentasi

API Lunas

Tiga endpoint untuk menerima pembayaran QRIS dari aplikasi atau toko online-mu: buat tagihan, cek status, dan terima notifikasi settlement.

Ringkasan

Semua permintaan memakai JSON melalui HTTPS. Base URL:

https://api.lunas.id/v1
Dokumentasi ini adalah contoh halaman produk. Kunci API di bawah hanya placeholder.

Autentikasi

Setiap permintaan menyertakan API key rahasia di header Authorization. Jangan pernah menaruh kunci ini di kode frontend.

Authorization: Bearer sk_live_xxxxxxxxxxxxx

Buat QRIS

POST /payments membuat tagihan dan mengembalikan payload QRIS siap tampil.

FieldTipeKeterangan
amountintegerNominal dalam rupiah, minimal 1000.
referencestringID pesanan milikmu, unik.
descriptionstringKeterangan yang tampil ke pembeli.
expires_inintegerMasa berlaku dalam detik, default 900.
 
curl -X POST https://api.lunas.id/v1/payments \
  -H "Authorization: Bearer sk_live_xxxxx" \
  -H "Content-Type: application/json" \
  -d '{
    "amount": 384000,
    "reference": "INV-2098",
    "description": "Kopi Susu 2x - Croissant",
    "expires_in": 900
  }'
{
  "id": "pay_9f2c1a",
  "reference": "INV-2098",
  "amount": 384000,
  "fee": 2688,
  "net_amount": 381312,
  "status": "pending",
  "qr_string": "00020101021226670016COM.LUNAS.WWW0118...",
  "qr_image_url": "https://api.lunas.id/v1/qr/pay_9f2c1a.png",
  "expires_at": "2026-11-17T13:45:00Z"
}

Cek status

GET /payments/{id} mengembalikan status terkini. Gunakan ini sebagai cadangan bila webhook terlewat.

curl https://api.lunas.id/v1/payments/pay_9f2c1a \
  -H "Authorization: Bearer sk_live_xxxxx"

Nilai status yang mungkin:

  • pending — QR sudah dibuat, belum dibayar
  • paid — pembayaran diterima, dana tercatat
  • expired — melewati masa berlaku
  • refunded — dana dikembalikan ke pembeli

Webhook

Lunas mengirim POST ke URL notifikasi milikmu saat status berubah. Selalu balas dengan HTTP 200 dalam 5 detik; bila gagal, kami mencoba ulang 5 kali dengan jeda bertahap.

{
  "event": "payment.paid",
  "created_at": "2026-11-17T12:31:08Z",
  "data": {
    "id": "pay_9f2c1a",
    "reference": "INV-2098",
    "amount": 384000,
    "fee": 2688,
    "net_amount": 381312,
    "method": "QRIS",
    "issuer": "gopay",
    "paid_at": "2026-11-17T12:31:06Z"
  }
}

Verifikasi keaslian dengan header X-Lunas-Signature (HMAC SHA-256 dari body memakai webhook secret).

Kode uji
